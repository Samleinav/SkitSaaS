# Theme Development

This section is the Botble-style navigation layer for SkitSaaS theme authoring.
It intentionally repeats some information from the main docs so theme work can
be explored in one place.

## What This Section Covers

Use this section when the task is:

- creating a new theme pack
- understanding `theme.json`, `config.ts`, and `routes.ts`
- working on admin, dashboard, or frontend theme surfaces
- authoring CTC templates
- adding theme assets and locales
