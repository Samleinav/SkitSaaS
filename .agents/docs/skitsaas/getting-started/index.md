# Getting Started

This section is the Botble-style onboarding layer for SkitSaaS. It exists so a
developer or agent can get the platform running or reason about deployment
shape without having to reconstruct setup from scattered notes.

## What This Section Covers

Use this section when the task is:

- getting the app running locally for the first time
- understanding the first login and seed workflow
- deciding whether to stay single-service or split deployments
- checking which env values are truly required to boot the platform

## Read Order

1. [Simple SaaS](./simple-saas.md)
2. [Multi-Service Deployment](./multi-service.md)
3. `../reference/env-and-runtime-config.md`

## Practical Rule

Start simple unless there is a concrete reason to split services.

Single-service is the right mental model for most local work and for many early
deployments.
